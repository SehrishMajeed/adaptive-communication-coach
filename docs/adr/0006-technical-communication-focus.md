# ADR 0006: focus on technical explanations for a specific audience

Status: accepted product direction; existing generic soft-skills copy needs alignment.

## Context

Engineers, students and researchers often need to explain the same idea to audiences with different knowledge and goals. Generic public-speaking scores obscure what a useful explanation should achieve and encourage unsupported visual or confidence judgments.

## Decision

Focus on a technical explanation with explicit topic, audience, communication goal and duration. Train one supported weakness through a comparable retry. Full, muted and audio-only review support personal reflection; they do not imply automated presence scoring.

## Alternatives

A broad public-speaking app increases feature and rubric scope before reliability exists. A technical answer grader measures correctness rather than communication and requires additional validation. Generic chat feedback lacks a controlled task and measurable retry target.

## Consequences

Rubrics and interventions must account for audience and goal. The product is intentionally narrower, making meaningful evaluation and a coherent demo possible. Scenario selection and session semantics are core domain concerns; social features and generic dashboards are not priorities.
