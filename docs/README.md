# Project documentation

The repository is a prototype with reproduced correctness failures. This documentation describes both the audited implementation and the intended direction; target designs are not shipped capabilities. No application changes were made during this phase.

- [Current-state audit](current-state-audit.md): end-to-end trace, prioritized findings, verification results, claim ledger and first implementation PR.
- [Product](product.md): focused user problem, practice loop, principles and candidate success measures.
- [Target architecture](target-architecture.md): current and proposed flows, responsibilities and failure/privacy boundaries.
- [Domain model](domain-model.md): conceptual entities, lifecycle, ownership and retention.
- [Testing strategy](testing-strategy.md): offline CI, integration, workflow and browser coverage.
- [Evaluation strategy](evaluation-strategy.md): future reliability experiments; no invented results.
- [Roadmap](roadmap.md): nine phases with acceptance criteria and non-goals.
- [Architecture decisions](adr/README.md): six decisions and their tradeoffs.
